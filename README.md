# ai-happy-01 entry

Entry for the make.fun bounty [ai-happy-01](https://make.fun/bounty/ai-happy-01):
a program that writes one image, made to make the AI judge happy, to `/output/entry.png`.

A warm, appetizing bowl of shrimp and egg ramen — comfort food that makes people (and judges) smile.

- `entry.png` — the image (1024x1024 JPEG)
- `main.py` — copies `entry.png` to `/output/entry.png` (no network, deterministic)

Run: `python3 main.py`
